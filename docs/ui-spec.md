# UI 仕様

参考にしたのは [Synergy!](https://www.synergy-marketing.co.jp/cloud/synergy/) の情報設計と、指示書で指定された他の診断系サイトの「見せ方」です。
文章・画像・ロゴ・配色のコピーはしていません。ワンマケ向けに再構成しています。

詳細な観察メモは `docs/analysis.md` の §7 にあります。

---

## 1. デザイン原則

- 安心して使える・読みやすい・怪しさがない・結果がすぐ分かる、を優先する。
- 黒・金のダーク系や過度な高級感には寄せない。
- 白基調、薄いピンク／クリームのセクション分け。CTA は明るいコーラル、副ボタンはティール。
- 数字を並べすぎない。結論を先に出す。

主色はコーラル `#FF3D2E`（CTA・見出し強調・ロゴ）。補助色はティール `#00A3AE`（ログインなど副ボタン）。判定色は割安＝ティール、相場通り＝青、割高＝テラコッタです。

コンテンツ幅は最大 1080px。カードは角丸 16px、ボタン高さ 48px、入力は 16px（iOS のズーム防止）。

---

## 2. 画面構成

| パス | 画面 | 誰が使うか |
| --- | --- | --- |
| `/` | LP | 未ログインでも可 |
| `/diagnosis/new` | 物件入力 | 未ログインでも可。会員登録は求めない |
| `/signup` | 会員登録 | 入力後。`?next=/diagnosis/run` |
| `/login` | ログイン | 同上 |
| `/diagnosis/run` | 診断実行 | 要ログイン。下書きを送る |
| `/diagnosis/[id]` | 診断結果 | 本人のみ |
| `/mypage` | マイページ | 要ログイン |
| `/checkout/success` `/cancel` | 決済戻り | 権限付与は Webhook 側 |
| `/admin/*` | 管理 | `ADMIN` のみ。それ以外は 404 |

フッターに LP アンカー、入力、登録、ログイン、マイページを置きます。電話番号の常時表示や受賞バッジは作りません。

## 3. LP

ファーストビューで「その提案価格は、相場と比べてどうですか？」と問い、
「無料で相場を確認してみる」を折り返しの上に置きます。

続くセクション順:

1. ワンマケとは
2. 分かること（割安/相場/割高、相場価格帯、差額）
3. ご利用の流れ（入力 → 登録 → 結果）
4. 安心して使うための説明
5. よくあるご質問
6. 注意事項とフッター

CTA 文言は指示書どおり「無料で相場を確認してみる」を使います。
誇張した実績数値は出しません。算出方法と免責を淡々と書きます。

---

## 4. 入力フォーム

診断の 7 項目はそのまま使い、その前段に所在地を置きます（`docs/analysis.md` ASSUMPTION-1）。

| ステップ | 項目 | 単位 |
| --- | --- | --- |
| 1. 所在地 | 都道府県（必須セレクト）、市区町村 | — |
| 2. 建物 | 最寄り駅、駅徒歩、築年数、物件価格 | 分 / 年 / 万円 |
| 3. 収支 | 月額賃料、管理費、修繕積立金 | 円 |

- ラベルと入力欄を `htmlFor` / `id` で対応させる。
- 必須バッジ、プレースホルダ、補足（例: 2,670万円なら「2670」）を付ける。
- 駅名は都道府県スコープの候補（datalist）。曖昧検索で別駅へ飛ばさない。
- エラーは項目直下に日本語で出す。何を直せばよいか分かる文にする。
- 入力は `sessionStorage` に保持し、再読み込みや登録画面への往復でも消さない。
- 送信ボタンは「この物件の相場を確認してみる」。スマホでは画面下に固定する。

未ログインでもこの画面は開けます。登録案内は送信後です。

---

## 5. 診断結果

開いた瞬間に判定が分かるようにします。内部収益率・エリアコード・シート名は出しません。

1. 見出し「この物件は相場より高めです」等とバッジ「判定：割高」
2. 相場価格（万円帯）と提示価格
3. 「相場より ○○万円〜○○万円 ほど高い／安い価格です」
4. 入力した物件の要約（所在地・駅・築年数・収支）
5. 免責。金額は 1 万円単位に丸めていること、参考情報であることを書く

---

## 6. 会員・マイページ・管理

- 登録はメール・パスワード（8 文字以上）・任意の表示名。
- マイページはアカウント、無料/有料の利用状況、診断履歴のみ。分析ダッシュボードは作らない。
- 2 回目以降は「2回目以降の診断は有料です」。Stripe 未設定時は「準備中」。
- 管理画面は概要・ユーザー・診断・決済・収益率データの閲覧。編集 UI は MVP 外。
- 管理画面は一般ユーザーには 404 として扱う。

---

## 7. レスポンシブとアクセシビリティ

- スマホ優先。横スクロールしない。本文は 15px 以上。タップ領域は 48px。
- キーボード操作と `:focus-visible` のアウトライン。
- エラーは `role="alert"`。コントラストは本文インク `#10181C` と白地。
- `prefers-reduced-motion` でアニメーションを切る。
