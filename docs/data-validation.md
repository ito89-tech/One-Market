## 2. BLOCKER（診断に使えないセル）

**東京・埼玉・神奈川・千葉 / ④エリア / 築35以上 / `4.70%-4.49%`**

下限 4.70 が上限 4.49 を上回っています。隣接する築 30〜34 年は `4.60%-4.79%` ですが、推測して直しません。

対応:

- `valid: false` として取り込む
- 該当条件の診断は `DATA_UNAVAILABLE`（無料回数は消費しない）
- 管理画面の「収益率データ」に常時表示する

**クライアントへ:** 正しい値をご指定ください。
